抹茶名店互動地圖APP <br>
核心功能 (Key Features)

地圖與列表雙向互動 (Two-way Data Binding)：點擊地圖上的標記可查看店家資訊，點擊側邊欄店家列表則地圖會平滑飛移（flyTo）至該位置並彈出詳細卡片。

多維度篩選與搜尋 (Search & Filtering)：支援關鍵字即時搜尋（店名、城市、招牌餐點）與地區快速標籤篩選（全台灣、北部、中部、南部）。

響應式排版 (Responsive Web Design)：針對桌面與行動裝置優化。手機版提供抽屜式選單，避免地圖內容被遮蔽。

地理定位 (Geolocation)：整合瀏覽器 GPS 定位功能，幫助使用者快速尋找附近的抹茶名店。
